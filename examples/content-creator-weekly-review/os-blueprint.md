# 민지(가상)의 OS 청사진

**작성일**: 2026-05-03
**OS 선언문**: 나는 **내가 진짜 하고 싶은 말을 결정하는 일**만 하고, 나머지는 시스템이 한다.

---

## 1. 풍경 (지금)

1인 유튜브 채널 운영. 주제는 디자인 툴 리뷰·튜토리얼. 시간을 가장 많이 쓰는 활동:
- 영상 기획 (소재 발굴 + 대본 작성) — 주 8시간
- 촬영·편집 — 주 12시간
- 발행 후 댓글·DM 응대 — 주 4시간

> Claude의 가설 검증: "그러면 채널 운영 시간 중 **40%가 기획 단계**라는 건데, 맞나요?" → 민지 "네, 맞아요. 근데 기획에서 늘 헤매요."

---

## 2. 통점 (반복 비용)

매주 영상 1개 발행이 목표인데 평균 1.6주에 1개로 밀린다. 가장 자주 막히는 지점은 **기획 단계의 시작 결정**:

- 일요일 저녁에 "이번 주는 뭘 다룰지" 정하느라 2~3시간 소진
- 결정된 다음에는 작업이 잘 굴러감 (촬영·편집은 흐름 있음)
- → **시작 전 결정 비용**이 가장 무거움 (Step 2 가설 검증 결과)

부수적으로:
- 댓글에서 다음 주제의 힌트가 자주 나오는데, 댓글이 흩어져 있어서 통합 관리가 안 됨
- 발행 후 일주일 지나면 댓글을 다시 안 봄

---

## 3. 이상향 (이게 풀리면)

> 일요일 저녁에 책상 앞에 앉으면 **이번 주 다룰 주제 후보 3개가 이미 정리되어 있고**, 각 후보에는 "왜 이 주제인지" + "기존 시청자 댓글 중 관련된 것 2~3개" + "유사 주제로 잘 된 영상 1~2개 (참고)" 가 붙어있는 상태. 나는 그중 **하나를 고르기만 하면** 된다.

→ "결정"은 내가 하지만, "결정의 재료"는 시스템이 모아온다.

---

## 4. 부품 후보 (도달 경로)

- [ ] **댓글 통합 인박스** — 일주일치 댓글·DM을 한 화면에 모아 카테고리별로 정리
- [x] **주간 기획 인터뷰** ← **첫 부품 (이번에 만들 것)** — 일요일 저녁에 발동, 시청자 반응 + 트렌드를 묻고 다음 주 주제 후보 3개를 뽑아줌
- [ ] **영상 메타데이터 자동 생성기** — 편집 끝난 영상 파일 → 제목·설명·태그·썸네일 가이드 초안
- [ ] **댓글 → 다음 콘텐츠 힌트 추출기** — 발행 후 1주일 댓글에서 다음 주제 신호 자동 추출
- [ ] **월간 회고 카드** — 이번 달 영상 4개의 조회수·댓글·진행시간 분포로 다음 달 방향 제안

> Claude의 가설 검증: "5개 부품을 (a)입력 처리 / (b)결정 보조 / (c)출력 생성 으로 나누면, **결정 보조가 가장 비어있어요**. 첫 부품을 거기 두는 게 효과 클 것 같은데 맞나요?" → 민지 "맞아요, 결정 보조가 핵심."

## 5. 첫 부품

- **이름**: 주간 기획 인터뷰 (`weekly-content-review`)
- **형태**: **A. Claude 스킬** (`SKILL.md`)
- **결과물 파일**: [`weekly-content-review.skill.md`](./weekly-content-review.skill.md)
- **선택 이유**: 입력이 "내 머릿속 + 지난 주 시청자 댓글 메모"이고, 출력이 "주제 후보 3개의 마크다운". 둘 다 텍스트 기반이고 Claude 안에서 끝남 → A가 가장 가볍고 빠름.
